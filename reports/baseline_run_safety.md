# 基线运行与结果保护

本次修改不改变词典、HMM、CRF 的算法，不重新训练已有模型。

## 手动启动新实验

在项目根目录执行（以下命令会训练模型，请准备好后自行运行）：

```powershell
.\.venv\Scripts\python.exe scripts/run_baselines.py --smoke --output-dir runs/smoke_baselines_review
.\.venv\Scripts\python.exe scripts/run_baselines.py --output-dir runs/baselines_review
```

两条命令是独立的运行选择：第一条只用前 100 条有效 Train 和前 20 条 Dev 检查流程；第二条运行完整基线参数实验。烟雾测试分数不能作为正式结果。

## 校验和续跑

- 加载数据前核对清单中实际文件的 SHA-256，并确认配置引用的数据文件都在清单中。
- 指纹包含数据清单、数据配置、相关代码、Python/平台和数值计算及 CRF 依赖版本。
- 训练前检查所有已有模型目录。指纹相同且模型、预测、指标及错误分析文件哈希完整时，才复用缓存。
- 再次执行完全相同的命令，可跳过已经完成且验证通过的模型。
- 如果一个模型训练中断、产物不完整，脚本会停止。请使用一个新的输出目录重新运行，不会自动删除或覆盖残留结果。
- 原有实验没有新增的完整产物哈希，因此不会被当作可信新缓存复用，也不会被自动补写或覆盖。
- 不要同时向同一个输出目录启动两个进程；目前没有并发运行锁。

## 与正式 Test 的关系

新目录保存自己的 `selection.json`。目前 `run_final.py` 仍使用原先的 `runs/baselines` 和冻结配置，不会自动读取新目录。若以后决定以新实验进行正式测试，应先明确新的实验版本与冻结流程；不要直接覆盖原目录或删除冻结文件。

基线、运行安全和评估器测试共 33 项通过。新增测试包括 HMM 手算概率与 UNK 聚合、跨类别 BIO 约束、CRF 特征不读取金标，以及数据变更、缓存损坏、旧缓存和部分完成目录的拒绝复用。
