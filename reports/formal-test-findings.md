# 固定 Test 的主要发现与解释边界

本分支 Test 1,209 句、2,687 个实体；方法、提示和分析规则已在预测前提交冻结，提交 `a67703d`。所有数值来自实际保存的预测。

- CRF 实体 F1 为 70.75%，4-shot 为 69.36%；Token F1 则分别为 74.49% 和 74.78%，出现排名差异。两套主指标使用同一规范化实体集合。
- 4-shot 比 CRF 多 43 个严格 TP（1,856 对 1,813），同时多 184 个 FP（809 对 625），因此 Recall 较高而 Precision 较低。严格实体 F1 并非只由抽中多少实体决定。
- 预先声明的 Train 文本及类别分组中，CRF 在见过组 F1 为 83.63%，4-shot 为 77.22%；未见组则为 46.64% 和 56.92%。未见 gold 共 995 个，占 37.03%。该分组是本项目 Train 覆盖诊断，未控制类别、长度和难度，也不代表商业 LLM 的预训练未知实体。
- 词典在未见组 TP=0，符合其输出只能来自 Train 词条的结构预期；见过组 Recall 为 94.50%。这一结果帮助区分完整名称记忆与组合泛化的行为，但不是因果机制证明。
- 4-shot 减 CRF 的整体实体 F1 差值为 −1.39 个百分点，配对百分位 95% 区间 [−3.47,+0.69]；4-shot 减零样本为 +12.54，[+10.84,+14.38]。2,000 次句子配对抽样，固定种子；区间描述性、未作多重比较校正，不覆盖重新训练和生成的波动。
- 零样本及 4-shot 的坐标错误句分别为 24 和 16；识别边界及类别问题仍存在，不能把所有误差归因于字符定位。没有按金标准改坐标或增加隐藏修复调用。

可追踪的实际例子：`train:5915` 中未收录的“光谱”company 被 4-shot 识别、CRF 漏抽；`train:1889` 中“冀欣”“李雯珊”被 CRF 合并、4-shot 分开；`train:578` 中收录过的“招商银行信用卡中心”被 CRF 完整识别、4-shot 拆分。它们是说明性案例，未独立人工核验。

上述 `train:` 是官方来源 ID 前缀，这些 ID 均属于本项目冻结 Test。与 main 的 Test 划分和主评分协议不同，不能将分支数值直接作公平排名。
