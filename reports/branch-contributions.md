# 本分支的实验贡献与证据范围

分支：`codex/cluener-dual-eval-traditional-dev`。本分支沿用 CLUENER2020 五类系统作为共同基线，形成下面三条可复核的分析线。

| 问题 | 实施 | 证据 | 结论边界 |
|---|---|---|---|
| 索引表示与终点解释分别怎样影响定位？ | 固定四条 Train 示例，在排除既有 300 条调参 Dev 后的 200 句上做 2×2 对照，共 800 次请求 | `index-factorial-results.md`、`index-factorial-contrasts.csv`、冻结配置与请求哈希 | 三列索引观察到更少坐标错误；实体 F1 差值区间仍含零，不宣称普遍改善 |
| 两级分数差异来自粒度还是后处理？ | 两套主指标统一使用合法、去重、非重叠跨度；原始跨度、忽略坐标的 text+type 分数单列诊断 | `formal-test-results.csv`、逐句原始计数及本地诊断日志 | 诊断分数不混入主表，text+type 无法辨别重复名称的位置，不能视作主指标上界 |
| 总分中有多少表现对应 Train 收录的名称？ | Test 前声明按有效 Train 的完整 `(entity text,type)` 对 gold 和预测同时分组，核对各组 TP/FP/FN 可加回全局计数 | `formal-test-novelty.csv`、预提交的 `configs/formal_test_v1.json` | 项目 Train 未见不代表 LLM 预训练未见；分组难度、长度和类别不同，不能直接作因果归因 |

正式 Test 使用本分支固定 1,209 句，在所有方法和分析规则提交冻结后运行。传统模型复用 Dev 选出的确切模型；LLM 原样使用试跑 v2 提示和 Dev 选出的四条 Train 示例。配对 Bootstrap 对固定预测进行句子重采样，区间不覆盖重新训练及重新生成的不确定性。

词典/HMM/CRF、0/2/4/8-shot 及 Bootstrap 本身是常用方法，不作为新架构贡献。当前贡献定位为问题明确、接口可审计、对照可复核的课程实验；未开展文献首创性审计，不宣称首次提出这些思想。

与 main 的划分种子、项目 Test ID 和主评分协议存在差异，不能直接拿两个分支的 Test 数值作公平排名。独立讲解材料保存在仓库外；本文件只记录实验贡献和证据来源。

人工核验仍需两人真实完成。程序仅生成 40 个错误事件及其中 20 个独立复核任务，不将空白模板或自动分类冒充人工结论。
