# 统一结果图表约定

本任务沿用现有Python/matplotlib工作流；本文件先于新图生成。目标是课程实验报告，不声明期刊投稿规范认证。

- 科学问题：同一CLUENER Test及同一V3口径下，传统方法与三种API模型的表现、Shot变化及成本有何差异；网络故障怎样限制结论。
- 数据：完整1209句、15组全部观测；不按Test成绩排序/筛选模型。另建所有方法相同的网络可用共同子集，只作为条件性诊断，不替代完整Test，不删除内容拒绝/格式失败。
- 主图：两级F1全方法点区间图；三模型实体Shot曲线、字符BIO Shot曲线；共同子集实体曲线；相对CRF的句子配对差值；已返回usage费用曲线。
- 每张图只含一个数据坐标轴，属于quantitative单图。多面板对齐不适用；仍保存该状态并执行最终PDF字体/碰撞检查。
- 误差线：2000次句子级配对Bootstrap百分位95%区间，同一抽样索引用于全部方法；差值直接对同轮差值求区间。固定预测、单划分、单示例池；不覆盖训练/API重复运行，不做多重比较校正，不画显著性星号。
- Shot仅连接0/2/4/8实际观测，连接线仅作阅读引导，无中间点或外推。GLM4-shot标记117条连接失败；共同子集图注明实际n及条件性筛选。
- 费用是一次运行真实usage按记录价格计算的观测，不画虚构置信区间；GLM未知预留不混成已返回费用，单独表格说明。缓存命中率、思考模式及输出上限不同，不能归因为架构。
- 改编级别：仅沿用现有绘图脚本的字体、点区间语法和留白风格；数据映射及15组/三模型比较逻辑重新实现。
- 字段：main_results.csv的token/entity_f1及ci列→点/区间（百分比）；bootstrap_comparisons.csv→配对差值（百分点）；cost_latency.csv→已返回费用（元/1209句）；network_subset.csv→同一受限子集的指标。
- 输出：约183 mm宽；字体≥7.5 pt，SVG保留文字、PDF TrueType，300 dpi PNG用于课程预览，SVG/PDF为矢量主文件；不要求TIFF。每图有源表哈希、脚本和QA记录。
- 不使用生成图片、模拟分数或装饰性插值。自动QA后逐图视觉检查；字体、曲线、区间和标注布局变化后重新导出并重做PDF检查。
