# 当前 V3 结果图：绘制与解释约定

用途：课程报告与讲解，不套用特定期刊的投稿要求。沿用项目 Python/matplotlib 工作流。

证据范围：固定1209条Test、三个传统基线及新版0/2/4/8-shot，全部重评为V3。不剔除句子、不根据Test选择单一LLM方案；传统模型参数沿用历史Dev选择，新版LLM没有重新做Dev选参。

绘制三张单坐标轴图，避免重复堆叠面板：

1. 两级指标比较：全部七个方法的Token/实体micro F1及句子Bootstrap区间。问题是局部字符正确与完整实体正确是否一致。
2. 配对差值图：新版四档相对CRF的实体micro F1差值区间。直接显示配对差值，不通过两条独立区间是否重叠代替差值推断。
3. Shot曲线：0/2/4/8为真实横坐标，点为固定预测F1，连线只连接实际观测档位。展示当前示例池下非单调关系，不插值外推或宣称因果。

统计约定：2000次句子级有放回配对重采样，seed=718853259；每次先汇总TP/FP/FN再算micro F1。同一轮索引用于所有模型。误差线为95%百分位区间，只反映固定预测下的样本波动，不包含训练/API/示例池随机性。区间为逐比较、未做多重比较校正；属于观察Test后的探索性分析，不绘制显著性星号，不报告伪p值。

导出：每图约183mm宽，字体至少8pt，白底，蓝/橙表示两种指标；传统与LLM不以红绿区分胜负。提供PNG预览、可编辑SVG/PDF以及源CSV。所有图为单轴，面板对齐记录不适用；PDF字号和碰撞检查与实际视觉检查均记录。

数据源：reports/tables/current_v3/main_results.csv、bootstrap.json与bootstrap_comparisons.csv。图注写明n、重采样次数、区间、选择条件及不能推断的范围。旧图保留，当前图另存reports/figures/current_v3。
