# 报告编写与证据分配

目标读者为课程教师与同学，采用用户指定的八节中文结构，不按期刊格式改写。主张限定为同一CLUENER项目Test、同一V3口径下的系统比较，不宣称架构普遍优劣。

术语固定：CLUENER2020；词典；隐马尔可夫模型HMM；条件随机场CRF；字符BIO集合式micro P/R/F1（Token指标）；严格实体级micro P/R/F1；Shot为一整条有效Train句子及金标；成本中的token是API计费token，与字符Token指标区分；百分点用于F1差值，百分比用于分数与比例。

正文证据分配：主表15组与双层指标是核心证据；Shot曲线及配对差值是支持；网络故障、协议历史、数据许可、thinking差异和未验证的换例句波动是改变结论范围的条件，必须留在正文。全量逐类150行、20个BIO标签300行、42组比较和完整请求响应放源表与本地证据，不全部堆进正文。

课程原理1：HMM词频阈值改变词表/UNK/F1，不能冒称比较了不同分词器。课程原理4：同参数BIO约束排除少量非法路径、实体F1不变，不能补造收益。课程原理10：两级指标排序差异、真实边界案例和V3重叠集合边界共同说明指标选择。

八节功能：①任务与可检验成功判据；②替代方案和不微调/不RAG的原因；③实际模块与架构图；④实现、数据审计、恢复和版本修订；⑤数据/指标/主表/参数/原理实证；⑥三个真实失败与结论边界；⑦费用/延迟/许可/AI声明/离线复现；⑧真实分工待填写。

结果均由CSV/JSON读入，报告生成记录源哈希。无学生姓名、工时、人工双人核验、控制台实际扣费或异机复现证据时保留待填写/未核验，不编造。外部文献仅解释既有方法与选型；未实验的BERT、LoRA和RAG不作为实测基线。
