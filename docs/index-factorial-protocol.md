# 独立贡献：字符定位表示与终点解释的 2×2 对照

只在 `codex/cluener-dual-eval-traditional-dev` 开展，main 是背景参照，不合并 main 的数据划分、评估器或结果。
本协议在新增真实请求之前固定。研究的是输出表示与说明的作用，不宣称提出新的 NER 架构。

## 问题与已有证据

历史 20 条 Dev 首版有 5 句话、7 个实体的文字与坐标不一致，均符合闭区间终点用于半开区间的特征。
第二版同时改变索引展示与说明，错误消失；由于改了多个因素且复用了适配样本，不能单独归因，也不能声称已独立验证。

新实验将两因素分开：

| 组 | 输入索引表示 | 终点解释 |
|---|---|---|
| A | [start,字符] | 仅共用的基本 [start,end) 定义 |
| B | [start,字符,end] | 同 A |
| C | 同 A | 额外明确末字符索引+1、例子及长度/切片检查 |
| D | 同 B | 同 C |

类别定义、语义边界规则、输出 start/end/type/text、非重叠要求、模型及解码参数一致。
系统提示只按解释因素改变；用户 JSON 只按表示因素改变。四条有效 Train 示例的 ID、顺序和标准输出一致，用户输入按本组格式呈现。
固定 4-shot 是因为该既定 Train 前缀覆盖十类，用于控制变量，不从 main 的 Test 表现选取。

## 数据与调用

从官方 Dev 的既有 1,343 条中排除历史试跑与既定 300 条调参子集，按 `SHA256(seed|index-factorial-v1|id)` 排序取前 200 条。
种子沿用 141595842，选择不读取标签。保存 ID、原文件哈希、完整请求哈希与代码快照后才能发请求。
这批样本未用于已有 LLM 试跑，但传统模型此前在完整 Dev 上选参，因此称为新的 LLM Dev 对照子集，不称为独立 Test。
不读取项目 Test 文本，不修改原划分或原始标注。

每条句子的四组请求按预先固定的哈希次序交错运行，最多四个在途请求，以减少整组先后运行带来的时间因素。
仍不能排除远程服务内部变化与单次生成波动；报告返回模型标识，temperature=0 也不保证完全确定。
请求共 800 次（重试另计）；沿用持久 SQLite 账本，全项目 100 元，本阶段 12 元；请求前事务性预留。
当天价格已核对；未知计费保留预留，遇到致命问题停止，不自动充值、隐藏修复、换样本或择优重抽。
缓存版本按组隔离；旧试跑键保持不变，旧目录不覆盖。旧源码可由原提交恢复，新实验单独保存源码快照。

## 指标与判读

主诊断终点：全部 200 句话中，至少一个输出越界或实体文字与切片不一致的比例。解析/网络失败率必须并列，不能用失败或少输出换取较低坐标错误率。
抽取效果仍按共同合法非重叠集合计算 Token/严格实体 micro P/R/F1，保留原始跨度敏感性分数、无效条目、重复及重叠统计。
额外计算忽略坐标的实体文字+类别多重集 micro F1，以诊断实体文字与坐标的差异；它不能确定同名重复提及的具体位置，不能替代 NER 主指标。
无效实体中原文恰好出现一次的文字计为“唯一可定位候选”；仅用于诊断，不自动纠正坐标、不读取 gold 来定位，也不保证类别正确。

预定比较为 B-A、C-A、D-B、D-C，以及交互作用 (D-C)-(B-A)。每次对同一组句子配对重采样，重新汇总 TP/FP/FN 计算 F1，重复 2,000 次。
报告坐标错误率、Token/实体 F1 与文字类别 bag F1 的差值及描述性 95% 百分位区间；不做未经预定的最佳子组筛选。
多重比较、先前启发式探索和未重复生成的限制应披露，不将这些 Dev 区间当作经多重性校正的确证检验。
即使无提升或性能下降也报告；评分差异只能与对应诊断共同解释，不能把两级 F1 差直接当作定位错误比例。
