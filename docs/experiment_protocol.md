# 历史实验协议（初版，保留追溯）

2026-10-28提示：本文记录初版V1和旧Prompt的计划，不能作为最新15组实验协议。尤其是重叠处理、无效预测评分、LLM完整Dev选参及40/20人审安排后来已变更。当前实际口径见[evaluation_v3.md](evaluation_v3.md)、[15组报告](../reports/integrated_results.md)与[整合复现说明](integration_reproduction.md)。下文保留原文，不倒改历史。

数据集CLUENER2020，10类实体，Unicode字符级位置，跨度[start,end)。原始数据不改动，项目划分单独保存。

原Train10748、Dev1343有标签；官方Test1345无标签。项目Train9539/Dev1343/Test1209，Dev字节不变，原Train完整分配。持久种子718853259只生成一次；按每句类别存在性做容量约束迭代分层，另统计实体次数。无精确重复/冲突；如出现则停止并输出人工审核记录。

唯一嵌套样本train:1506保留原标注且固定在Train，训练及提示统一跳过，有效训练9538。许可未明确，不自行认定开放许可。

词典仅从有效Train建表，类别按频次/字母顺序决定，左到右最长匹配。HMM为监督字符发射/BIO状态、UNK、加性平滑、对数Viterbi；alpha=0.01/0.1/1，最低频次1/2/3。主方案BIO合法解码，另按相同概率参数对比无约束解码。CRF使用±2字符、局部二元字符与字符类型，L-BFGS最多100次，(c1,c2)=(0,0.1)/(0.1,0.1)/(0.1,1)。完整Dev实体micro F1选参，同分训练+预测总耗时更低，再配置顺序。

逐字符20个非O完整BIO标签micro P/R/F1与严格实体micro P/R/F1并列。O→O不计TP，错误实体标签含B/I混淆计FP+FN，漏抽FN、误抽FP。辅以固定10类macro/每类实体指标及含O accuracy，零分母为0并保存原始计数。

预测ID缺失/重复/多余停止评分；显式API/格式失败为空预测。非法I统一修B，报告修复前非法位置数/全部字符位置数。重复实体去重另统计，越界/未知类型计总体实体FP，不投影字符；无法归属固定10类的无效项不进每类表，因此总体FP可能不等于分类型之和。invalid_sample_rate为含无效实体的句子占比，同时保存无效实体数量。重叠实体保留严格评分，字符投影按起点、同起点长度优先、类别排序去重叠并报告影响句数。

LLM为deepseek-flash，非思考、temperature=0、JSON模式、max_tokens=2048；固定20条试跑，300条Dev比较0/2/4/8示例。最佳少样本在2/4/8中按实体micro F1、延迟、示例数选择；零样本及最佳少样本执行完整Dev后冻结。示例从有效Train按新类别覆盖优先、固定类别顺序、种子哈希决定，前缀嵌套。提示包含类别、边界、原文与字符索引。保留返回模型别名，不把官网描述冒充实际返回了具体版本。

累计100元预算，调参最多20元，为完整Dev/Test留80元。高峰价格保守预算，记录低/高峰价费用范围，账单为准；未知计费失败保留预留金额。网络/429/5xx最多重试2次；认证不重试、格式不隐藏修复。8线程，单进程锁和预算线程锁。缓存按完整提示/参数/endpoint哈希；失败缓存也保留，避免择优重抽。原始响应、usage、耗时和错误留本地。

完整Dev选参后冻结数据/源码/配置哈希再评估固定Test，不在Test后改选参标准。错误先移除精确匹配，再对剩余跨度最大权重一对一配对：同边界、同类重叠、其他重叠依次优先，同层IoU；剩余漏抽/误抽。边界与类型同时错误单列，避免重复归因。

两种LLM分别与Dev最佳传统方法进行2000次句子级配对bootstrap，百分位95%区间，沿用持久种子；不能解释为训练随机性区间。人工复核40条，其中20条独立判断后复核，不以自动归因冒充人审。replay.py不调用API，要求所有保存预测重算指标完全一致。
